**To install this script**
  - download Openfront Lobbies.txt version
  - Tampermonkey Utlities
  - Import from file
  - Install
  - Make sure user scripts are enabled

This script does
  - Adds future lobbies on front page
  - Adds copy link button to future lobbies
  - When joining a future lobby it also copys the link to your clipboard

This script does NOT
  - Allow macros in game
  - cheating in game
  - contact external servers ( except openfront.io )
  - use cookies
  - read clipboard
